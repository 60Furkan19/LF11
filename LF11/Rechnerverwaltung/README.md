# Netzwerk-Rechnerverwaltung

WindowsForms-Beispiel zu Meilenstein 1 und 2.

## Starten

1. Den Ordner `Rechnerverwaltung` in Visual Studio öffnen.
2. Das Projekt als Startprojekt festlegen.
3. Mit **F5** starten.

Funktionen: Rechner anlegen, mehrere Rechner in einer `List<Rechner>` verwalten,
per ComboBox auswählen, Daten anzeigen und die IP-Adresse ändern.
